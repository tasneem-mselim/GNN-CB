## 📖 About the Benchmark
GNN-CB evaluates the state of GNN development across multiple domains. Each competition within this benchmark was designed to test specific graph properties:

*   **Heterogeneous & Homogeneous Graphs**
*   **Spatio-Temporal Dynamics**
*   **Hierarchical & Generative Modeling**
*   **Molecular & Biomedical Graph Analysis**

## 🏆 Human Leaderboard
The benchmark includes a comprehensive human performance study. Data is synchronized with the official project tables:
- **Task Complexity:** Ranked from Easy to Expert.
- **Statistical Baselines:** Includes Average (AVG), Standard Deviation (STD), High/Low scores, and Median performance for every competition.
